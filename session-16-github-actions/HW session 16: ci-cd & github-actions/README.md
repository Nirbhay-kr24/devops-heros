# CI/CD & GitHub Actions

## Overview

This project demonstrates a CI/CD pipeline using GitHub Actions.

### CI vs CD

- **CI (Continuous Integration):** Automatically tests and builds the application when code is pushed.
- **CD (Continuous Delivery/Deployment):** Automates delivery or deployment of the application after a successful build.

## GitHub Actions

GitHub Actions is used to automate the pipeline through YAML workflow files stored in:

```text
.github/workflows/
```

The pipeline demonstrates:

- **Workflow** – Automated CI/CD process
- **Jobs** – Test and Build jobs
- **Steps** – Individual commands executed by each job
- **Runners** – GitHub-hosted environment used to run jobs
- **Secrets** – Secure storage for sensitive credentials
- **Artifacts** – Files generated during a workflow run
- **Build & Test** – Automated application testing and building
